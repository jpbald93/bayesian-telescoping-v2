# Bayesian Telescoping Under Non-Ideal Conditions — corrected V2

**Paper:** *Telescoping Bayesian Inference with Approximate Forward Operators: Corrected Convergence
Theory, Multimodality as Loss of Injectivity, and the Cost of Heavy Tails*
**Author:** Josh Bald (Independent Researcher)
**Version:** V2, September 2026

This repository is the reproduction package for **V2**, a corrected revision of an earlier manuscript
(V1) on telescoping Bayesian inference with approximate forward operators. V2 **retracts** three of V1's
advertised contributions and replaces them with statements that survive independent audit.

> **Supersedes** the earlier `jpbald93/bayesian-telescoping` repository, whose archive did not reproduce
> any of V1's numerical tables.

## What V2 changes

| Claim | V1 | V2 |
|---|---|---|
| MLMC complexity regimes | threshold γ = β+1 | **corrected** to γ = β+2, with cutoff L ≍ ε^(−1/k) (the bias is O(L^(−k)), not O(L^(−(k+1)))) |
| Bimodality from a linear forward operator | implied possible | **Theorem (new): impossible** — affine F + Gaussian prior ⇒ the approximate posterior is exactly Gaussian, hence unimodal at every level |
| Bimodality from RK4 | "persistent even at n = 64" | **a coarse-level transient**: the RK4 stability function has an interior minimum at z⋆ = −1.5960716…; the numerical map folds at λ = z⋆n/T, so observable bimodality requires the fold to lie inside the prior's effective support |
| Heavy-tail penalty ρ(α) = (α−2)/(α−1) | presented as a sharp theorem | **not proved and not observed**; demoted to an explicit open conjecture |
| Telescope tail lemma | integral step in the wrong direction | fixed |
| Telescoping Kalman filter cost | O(T^(3/2)) | **Θ(T²)** — the claimed advantage vanishes |

V2 also replaces V1's numerical tables with experiments that are actually reproducible, and corrects
several citations (the heavy-tailed-prior reference and the "here be dragons" multimodal-posterior
reference were both mis-cited).

## Reproduce

```bash
cd code
python3 verify_bt_v2.py          # requires numpy + mpmath; exits nonzero on any failed assertion
```

The driver regenerates **every numeral** in the paper and *asserts* every claimed sign and threshold
(including a negative control: the superseded V1 cutoff/exponent pair must **not** reproduce the
corrected scaling). It prints `RESULT: ALL ASSERTIONS PASS` and exits 0.

Build the paper with:

```bash
cd paper && pdflatex bayesian_telescoping_v2 && pdflatex bayesian_telescoping_v2 && pdflatex bayesian_telescoping_v2
```

## Audit history

V2 went through three rounds of review:

1. **V1 → MAJOR REVISION (leaning reject)** by the author's own audit, independently reproduced.
2. **V2 → MAJOR REVISION** by an independent adversarial audit (vendor A). Real defects found — most of
   them *in the corrections themselves*: the MLMC cutoff, a false credible-interval proposition, a hidden
   RK4 mode, an inconsistent Hellinger normalisation, a wrong tail-sum statement, and a Hessian written
   with respect to the wrong reference measure.
3. After repair: **ACCEPT WITH MINOR REVISIONS** by a second independent adversarial audit (vendor B),
   followed by six further (mostly cosmetic/consistency) repairs.

All findings were re-verified by the author with independent code before being acted on; both audit
reports are included verbatim in `reports/`.

## Evidence tiers

Claims in the paper are labelled by how they are established:

- **proved** (theorem + written proof);
- **verified numerically** (regenerated by the shipped driver);
- **conjecture / open problem** (stated as such).

No claim in V2 rests on an experiment that is not in this repository.
